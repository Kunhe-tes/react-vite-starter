# 页面与组件开发

## 有原型时

1. 保留原始 HTML 和相对路径资源。使用设计稿时，记录可见区块、已有状态和待确认的交互。
2. 梳理区块、数据来源、布局、滚动边界和关键操作。按区块迁移为 React 组件，将 DOM 拼接和事件代理改为声明式渲染。
3. 用相同的数据和视口对照原型，核对默认值、筛选、确认、取消、重置和空态，记录差异及待确认事项。

## 无原型时

1. 明确页面用途、用户角色、首版主流程、字段口径、目标浏览器和部署路径。
2. 梳理页面区块、数据流、操作结果和异常状态。先实现可独立运行的核心流程，再补齐边界。
3. 记录待确认事项，按首版流程验证页面状态和操作结果。

## 目录、路由与样式

- `index.html` 和 `src/main.tsx` 是唯一的 HTML 与 React 挂载入口。`src/App.tsx` 装配路由。独立 URL 页面在 `src/routes.tsx` 中登记并按需加载，页内视角用 React 状态切换。

页面内按「页面入口 → 布局 → 业务区块 → 子组件」组织。以下目录按实际职责创建，简单页面从 `index.tsx` 开始即可。

```text
src/
├── pages/
│   └── <PageName>/
│       ├── index.tsx                  页面装配、查询与跨区块状态
│       ├── layout/
│       │   ├── index.tsx              页面骨架与区块排列
│       │   └── index.less             区块间距、布局断点与滚动边界
│       ├── components/
│       │   ├── <Section>/
│       │   │   ├── index.tsx          独立业务区块
│       │   │   ├── index.less         区块内部样式
│       │   │   └── <ChildComponent>/  仅由该区块使用的子组件
│       │   └── common/               本页多个区块复用的组件
│       └── data/                     页面专用的数据获取与转换
├── components/                       跨页面复用的组件
└── styles/
    └── base.less                      全局基础样式
```

- 先以完整业务区块为组件边界。有独立维护、实际复用或长期演进需求时，再在所属区块内拆出子组件。用业务名称命名区块，方便从页面定位源码。
- 组件目录以 `index.tsx` 为入口。有专属 Less 样式时放在同目录的 `index.less`，由组件入口导入。布局层负责区块之间的排列和滚动边界，区块负责内部排版与响应式规则，宽表在自身容器内横向滚动。
- 页面专用查询和数据转换留在 `data/`，跨页共用的请求逻辑沿用项目的公共接口层。 [接口、Mock 与持久化](api-and-data.md)

## 组件、状态与编码

- 按可独立维护的业务区块拆分组件。组件在模块顶层定义，避免父组件每次渲染都生成新组件类型，导致子组件重新挂载。列表使用稳定 ID。
- 使用函数组件和声明式渲染，用户操作放在事件回调中。Effect 用于外部同步、DOM 测量或焦点管理，完整声明依赖，监听、订阅和定时器随组件清理。
- 局部状态留在使用它的组件，共享状态放到最近的共同父层。子树内深层共享时按需使用 Context，跨页共享优先复用项目现有方案。
- 派生值从现有数据计算，草稿与已应用值分别管理。明确应用、取消和重置时机。级联筛选中，父级改变时一次更新需要重置的子级与页码。
- 新状态依赖上一次状态时使用函数式更新，例如 `setCount((count) => count + 1)`。
- 显式定义组件 Props 和业务模型。外部数据在边界校验，结构未知时用 `unknown` 接收，避免用 `any` 或未经校验的类型断言绕过检查。
- 组件和组件目录使用 PascalCase，函数和变量使用 camelCase，事件 Props 以 `on` 开头。代码遵循 Prettier 配置，控制语句使用大括号，由 ESLint 的 `curly` 规则校验。

## 加载与渲染性能

- 使用依赖公开支持的导入入口。有细粒度公开入口时按需导入，避免通过一个汇总入口拉入不相关的模块。
- 图表、编辑器等重型模块按路由或首次使用动态加载。通过 Vite 构建产物和浏览器网络面板确认首屏只请求当前流程所需的分包。
- 简单派生值直接计算。定位到昂贵计算或重复渲染后，再选用 `useMemo`、`memo` 或 `useCallback`，并复测受影响的交互。
